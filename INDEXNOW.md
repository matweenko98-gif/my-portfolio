# IndexNow для KSENWEB

Ключ размещён в `public/f19c7b9d5b475ad8b316c74394004e1c.txt`.
Middleware пропускает статические `.txt` файлы; Vite копирует ключ в корень сборки.

После публикации новых или изменённых страниц на основном домене:

```sh
npm run indexnow -- /blog/new-article /blog
npm run indexnow -- /case/new-case /cases
```

При смене адреса отправьте старый и новый URL, при удалении — удалённый URL.
Не отправляйте черновики, страницы с noindex и административные страницы.
Не отправляйте всю карту сайта при каждом изменении.
Команда проверяет доступность ключа, но допускает удалённые URL (404/410).
Для проверки без сетевого запроса добавьте `--dry-run`.

HTTP 200 означает принятие адресов; 202 — запрос принят, ключ ожидает проверки.
IndexNow не гарантирует включение страниц в поиск и не заменяет sitemap.
Отправка запускается командой: сохранение статьи в админке само по себе её не запускает.

Документация: https://yandex.ru/support/webmaster/ru/indexnow/reference
